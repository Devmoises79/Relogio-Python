# 🕒 Relógio Digital — Python + Tkinter

📌 Visão Geral

Este projeto é um relógio digital desenvolvido em Python com interface gráfica Tkinter, que exibe em tempo real a hora, data e dia da semana. A aplicação utiliza atualização contínua da interface para simular comportamento de tempo real.

# ⚙️ Funcionalidades

- Exibição de hora em tempo real (HH:MM:SS)
- Exibição de data completa (dia, mês e ano)
- Exibição do dia da semana
- Atualização automática a cada 200ms
- Interface gráfica simples e responsiva

# 🧠 Conceitos Aplicados (Engenharia de Software)

- Programação orientada a eventos (Tkinter)
- Manipulação de interface gráfica (GUI)
- Atualização contínua com after()
- Manipulação de data e hora com datetime
- Formatação de strings e dados temporais
- Controle de loop assíncrono na interface

# 🧩 Arquitetura do Sistema

- Tkinter → criação da interface gráfica
- datetime → captura e manipulação do tempo do sistema
- Função de atualização contínua → simula tempo real na UI

# 🚀 Tecnologias Utilizadas

- Python
- Tkinter (GUI nativo)
- Datetime (biblioteca padrão)

# 🎯 Objetivo do Projeto

O projeto foi desenvolvido com foco em:

- Prática de interfaces gráficas em Python
- Entendimento de eventos e atualização contínua de UI
- Manipulação de dados temporais em aplicações reais
- Construção de aplicações desktop simples e funcionais

# 📌 Resultado

Uma aplicação leve e funcional que simula um relógio digital em tempo real, servindo como base para evolução em interfaces gráficas mais complexas com Python.
